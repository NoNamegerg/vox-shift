## Русский

Vox Shift — настольное приложение для изменения голоса и воспроизведения звуков в реальном времени. Обработка выполняется локально на компьютере.

### Возможности

- 10 голосовых пресетов с настройками **Pitch**, **Formant** и **Robot**.
- Саундпад: добавляй собственные аудиоклипы, запускай и останавливай их, регулируй громкость.
- Звуки сохраняются на компьютере и остаются в панели после перезапуска приложения.
- Выбор микрофона и устройства вывода.
- Минималистичный тёмный интерфейс.

### Скачать

Скачай [VoxShift-Windows-x64.zip из последнего релиза](https://github.com/NoNamegerg/vox-shift/releases/latest), распакуй архив и запусти `VoxShift.exe`.

Саундпад поддерживает WAV, MP3, OGG, M4A, AAC, FLAC и WebM. Максимальный размер одного клипа — 30 МБ. Для использования звуков в Discord или игре выбери виртуальный аудиокабель, например VB-CABLE, как устройство вывода приложения, а его соответствующее устройство записи — как микрофон в игре. Наушники помогают избежать обратной связи.

### Запуск из исходников

Установи Node.js, затем выполни:

```powershell
npm install
npm start
```

## English

Vox Shift is a Windows desktop app for real-time voice effects and sound playback. Audio is processed locally on your computer.

### Features

- 10 voice presets with **Pitch**, **Formant**, and **Robot** controls.
- Soundboard: import your own audio clips, play or stop them, and adjust playback volume.
- Imported sounds are stored on your computer and remain available after restarting the app.
- Select your microphone and output device.
- Minimal dark interface.

### Download

Download [VoxShift-Windows-x64.zip from the latest release](https://github.com/NoNamegerg/vox-shift/releases/latest), extract it, and run `VoxShift.exe`.

The soundboard supports WAV, MP3, OGG, M4A, AAC, FLAC, and WebM files. Each clip can be up to 30 MB. To use the sounds in Discord or a game, select a virtual audio cable such as VB-CABLE as the app's output, then select its corresponding recording device as the microphone in your game. Headphones help prevent feedback.

### Run from source

Install Node.js, then run:

```powershell
npm install
npm start
```
