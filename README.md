# Vox Shift

Minimal real-time voice changer for Windows.

## Run

```powershell
npm install
npm start
```

Use headphones to avoid microphone feedback. To send the processed voice into Discord, games, or another app, select a virtual audio input such as VB-CABLE in that app and configure Vox Shift output to route it. The app can monitor and process the microphone locally; routing to Windows virtual microphone devices depends on the installed virtual audio driver.
